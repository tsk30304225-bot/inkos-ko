# 한국어 원고 검수

사용자가 기존 원고의 진단, 비교, 검수, 수정 조언을 원할 때 쓴다.

- 먼저 적용할 기준을 정한다: 장르, 대상 독자, 톤, 플랫폼, 작가의 명시적 선호. 일상 코미디, 순문학, 로맨스, 미스터리, 상업 연재가 같은 논리 밀도 기준을 공유하지 않는다.
- 진행 중인 작품에서는 저장된 회차를 auditor로 검수한다. 구체적인 문제 설명, 심각도, 근거(인용 또는 위치), 독자에게 미칠 영향을 보인다.
- 점수, 합격 판정, 별점을 만들지 않는다. 근거가 없으면 지적하지 않고, 근거가 있으면 완곡하게 덮지 않는다. 정보가 없으면 없다고 보고한다.
- 파서·모델 형식 실패는 review-unavailable 관찰이다. 원고가 나쁘다는 증거가 아니며 다시 쓰기를 허가하지 않는다.
- 사용자가 요청하거나 명시적인 생산 동작이 수정을 요청할 때만 수정하고, 수정본이 실제로 적용됐는지 보고한다.
- 작가의 목소리와 잘된 문장은 보존한다. 실제 결함을 해결하는 가장 작은 범위를 고른다.
- 장편에서는 회차를 채워진 memo 요구, 최근 전개, 실제 hook id, 인물의 앎, 독자와의 약속과 비교한다. 반복은 전진이 아니다. 회수·서브플롯·감정선은 사실·행동·관계·지위·이해가 바뀔 때만 움직인다.
- 원인에 따라 수정 경로를 나눈다: 문장 수준의 결함은 국소 수정(`local`), 빠진 장면·깨진 인과·시간선·시점·인물 논리·회수 문제는 구조 수정(`structural`).
- 한국어 문장 품질(번역투, 어미 반복, 호칭·존댓말 흔들림, 대사 화법)도 검수 범위다. 다만 작가가 고른 문체와 결함을 구별한다.
- 사용자의 언어로 답한다. 한국어 작품이면 관찰 요약과 수정 방향을 한국어로 쓰되, 관찰 코드·enum·hook id는 원래 값 그대로 둔다.

전체 검수를 하거나 기준에 이견이 있을 때 `references/review-matrix.md`를 불러온다. 이 표는 정성 기준이지 채점표가 아니다. 스핀오프는 원작(parent canon)을 권위로 쓰고, 동인은 `fanficMode`와 명시적으로 허용된 변경을 따른다.
