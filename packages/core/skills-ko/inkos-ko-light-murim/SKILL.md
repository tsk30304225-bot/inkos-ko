# 라이트 무협 문체 (경쾌한 코믹 프리셋)

출력 형식·도구 호출·JSON 키·hook id는 작업 프롬프트의 계약을 따른다. 이 스킬은 문체 방법론이다. 작가 지시·memo·book_rules·style_guide와 다르면 작품 쪽을 따른다.

## 다른 규칙과의 관계

이 프리셋(작품의 `story/korean_style_preset`이 `light-murim-comic`)에서는 기존 문장을 아래처럼 바꿔 읽는다. 프리셋이 없는 작품에는 이 절이 적용되지 않는다. 원래 문서는 고치지 않는다.

- 장르 문서 light-martial의 "'라이트'는 … 유아적 말투, 상시 개그, 무조건 무적, 갈등 삭제를 뜻하지 않는다" → 이 프리셋의 개그는 개그 문법(G1~G6)과 장면 유형별 개그 간격을 따른다. 분노, 윗사람과의 회상, 깨달음 구간, 존중형 결투는 개그 0이다(금지 8). 유아적 말투, 무조건 무적, 갈등 삭제는 여전히 실패다.
- 장르 문서 light-martial "흔한 실패"의 "구경꾼의 경악과 일방적 칭찬을 보상으로 반복한다" → 군중 일제 반응이 검수 판정 기준 '의도된 장치'의 정당 조건(계측기로 장면당 1~2회, 직후 1~3문장 안에 개별 인물 1명으로 좁힘)을 충족하면 실패가 아니다. 조건 밖의 반복과 일방적 칭찬은 여전히 실패다.
- 장르 문서 light-martial "흔한 실패"의 "모든 인물이 같은 현대 인터넷 말투를 쓴다. 현대 유행어·밈이 배경과 화자의 목소리를 무너뜨린다" → V6에 따라 주인공이 거만한 적에게 현대 속어로 응수하는 것은 응징·개그 장면에서 허용한다. 모든 인물이 같은 말투가 되는 것과 진지 장면의 속어는 여전히 결함이다.
- inkos-long-writing "검수·수정·다듬기"의 "군중이 일제히 놀라는 반응보다 … 관찰 가능한 반응 … 을 우선한다", korean-prose의 "군중이 일제히 `헉`, `말도 안 돼`라고 반응하는 장면은 한 사람의 구체적인 반응으로 바꾼다" → '의도된 장치'의 군중 일제 반응·피해자 합창 정당 조건을 충족하면 이 스킬의 기준을 따른다.
- korean-prose의 "같은 어미가 연달아 이어지지 않게 한다 … 세 번 넘게 이어지면 … 섞는다" → '의도된 장치'의 같은 어미 연속(현재형 실황 묶음, 과거형 묵직 서술), 후렴 동사, 발소리 반복, 같은 의성어 균일 3회는 정당 조건을 충족하면 결함이 아니다.

### 이 스킬 안에서 규칙이 부딪힐 때

| 충돌 | 내용 | 우선순위 |
|---|---|---|
| V1 속말 점령 vs V4 분노 장면 목소리 0 | 장면당 속말 2~4회 규칙이 분노 장면의 주인공에게도 적용될 수 있음 | V4 우선. 분노 장면에서 V1은 적과 아군에게만 적용 |
| R1 한 줄 문단 80% vs 분노·수련의 2~4문장 문단 | 공통 비율과 유형별 허용이 부딪힘 | 장면 유형별 수치 우선 |
| G4 김빼기 vs C6·윗사람 회상·깨달음 구간 금지 | 성장 완성 직후라는 조건이 이 장면들에도 해당될 수 있음 | 금지 우선 |
| R8 결정 대사 화 경계 vs R9 개그 정점 화 경계 | 한 화에 두 지점이 모두 생길 수 있음 | 한 화에 화 경계는 하나. 장면의 주 온도에 맞는 쪽 |
| R5 최장 의성어 희소성 vs R4 교정형 장음 | 교정형 장음(모음 6~7)이 최장 기록을 잠식할 수 있음 | 작품 최장은 응징형 전용으로 예약하고, 다른 유형은 그보다 3자 이상 짧게 |
| C3과 C8의 호명 핑퐁 | 같은 화에 둘 다 쓰면 호령이 중복됨 | 한 전투에 한 번 |
| V6 현대 속어 vs 금지의 진지 장면 속어 | C1 직후가 C9 정적형으로 이어지면 속어의 위치가 애매함 | 속어는 C1 본체에만. C9로 넘어가면 쓰지 않음 |

### 엔진 기본 규칙과 부딪히는 장치

auditor는 아래 장치를 기본 규칙으로 결함 처리하기 전에, 이 스킬 '검수 판정 기준 > 의도된 장치' 표의 정당 조건을 먼저 확인한다.

**군중 일제 반응 지양 규칙과 부딪히는 장치**
- 장내 일제 침묵 (G3 눈사태형의 정적, C9 정적형)
- 적 무리의 일제 후퇴·일제 돌격 (C4, C7)
- 장소 전체의 집단 체험 보도 (C1 리플레이, C5 집단 관전자)
- 피해자 속말 합창 (G6, 수련 집단형)
- 예상 밖 과잉 동조의 일제 대답 (수련 집단형)
- 아군의 동시 출격 (C8)

**같은 어미 반복 지양 규칙과 부딪히는 장치**
- 현재형 실황 묶음 (V7, C6 정점)
- 과거형 묵직 서술 연속 (분노, C7)
- 후렴 동사 (R9)
- 발소리 반복 (R4 분노형, C7)
- 같은 의성어 균일 3회 (C6)
- 동사 쉼표 반복 (C6 공세, 수련 단독형 순환)
- '~을 말이다' 도치 종결 (분노)
- 체언 종결 연속 (피해 나열, '말은 끝' 선언)
- 결핍 모티프 단어 반복 (G2)
- 핵심어 메아리 (회상)

**과장 지양 규칙과 부딪히는 장치**
- 멜로 과장 (화 끝 훅 정보 폭로형)
- 만화 물리학 (C1)
- 모의 서사시·모의 학술 보도 (V3)
- 작품 최장 의성어 (R5)
- 생활 비유 과장 (수련 성과 정리)
- 비유 상향 수정 (C3, C8)

## 서술 목소리

**V1. 속말 점령** [공통 / 강도는 서명]
- 조작: 시점 인물의 속말을 따옴표 없이 서술 자리에 놓는다. 장면당 2~4회. 조연과 적의 속말도 그 인물의 말투(비속어 포함) 그대로 쓴다. 정보가 확정된 직후에는 작은따옴표 독백, 따옴표 없는 1~2어절 의문, 따옴표 없는 15~30자 반문, 작은따옴표 감탄의 4단 계단으로 옮겨 간다.
- 기능: 서술과 인물의 거리가 0이 되어 독자가 인물 머릿속에서 같이 반응한다.
- 정당: 충격 정보 직후, 압박받는 인물, 시점 인물 1명에 한정할 때.
- 결함: 한 장면에서 시점 인물이 아닌 사람의 속말이 섞여 시점이 흐려질 때, 장면당 5회 이상일 때.
- 변형 방향: 따옴표 없는 속말의 말버릇은 참고작 고유 재료 대신 작품 고유 재료(작품 인물 고유의 입버릇)로 바꾼다.

**V2. 독자 편 서술자** [서명]
- 조작: 서술자가 주인공을 미화하지 않는다. 개그·일상에서는 인물 평가 한 문장, 인물의 격을 한 문장 안에서 강등하는 재명명, 독자 의문을 묻고 다음 줄에서 단정하는 자문자답을 쓴다. 진지·분노에서는 통념 인용(반문형 1회, 단정형 1회)으로 무게를 보증한다.
- 기능: 주인공이 아무리 강해도 오글거림이 생기지 않고, 서술자가 독자와 같이 웃거나 같이 긴장해 준다.
- 정당: 비꼼은 개그·일상·허세에서, 통념 인용은 분노·고전 전투에서.
- 결함: 분노·회상(윗사람 대화) 장면에서 비꼼, 주인공을 찬양하는 형용사('압도적인', '신과 같은').
- 변형 방향: 재명명의 비유 재료를 작품 세계의 직업, 신분, 물건으로 바꾼다.

**V3. 모의 서사시·모의 학술 보도** [서명]
- 조작: 저속하거나 사소한 사건일수록 장엄한 어휘('역사상 처음', '-고야 말았다')나 학술 어휘('새로운 사실의 발견', '~되는 중이었다')로 보도한다. 장면당 1~2회.
- 기능: 사건과 어휘의 체급 차이에서 서술 자체가 웃음을 만든다.
- 정당: 슬랩스틱, 집단 수련, 화 끝 줌아웃.
- 결함: 실제 비극이나 중상에 쓸 때(조롱으로 읽힘), 한 장면 3회 이상.
- 변형 방향: 역사서 대신 장부, 족보, 관청 공문 등 작품 세계의 문서 어투를 빌린다.

**V4. 주인공 목소리 온도계** [서명]
- 조작: 장면 온도에 따라 주인공 속말의 양을 정한다. 개그·일상·허세는 많이, 고전 전투는 호령만, 존중형 결투는 5~8자 독백 3회, 분노는 0회.
- 기능: 평소 시끄러운 주인공이 조용해지는 것으로 독자가 위험을 먼저 감지한다.
- 정당: 분노 장면 전체, 존중형 결투 전체.
- 결함: 분노 장면에서 주인공 독백 1회라도, 일상 장면에서 주인공 목소리가 사라져 존재감이 없을 때.
- 변형 방향: 목소리를 지우는 대신 주인공 말투의 특정 버릇(호칭, 말끝)이 사라지는 방식으로 신호를 줄 수도 있다.

**V5. 채점하는 주인공** [서명]
- 조작: 주인공은 싸우면서 상대를 채점한다. 존중형에서는 흥미, 인정, 승인의 짧은 독백 3단으로 점수가 오르고, 교정형에서는 승리 후 강평으로 채점 결과를 말한다.
- 기능: 주인공의 강함이 '이기는 힘'이 아니라 '보는 눈'으로 드러나 격이 올라간다.
- 정당: 압도 전투, 사제 대련.
- 결함: 모든 상대를 같은 점수로 대할 때(채점이 무의미해짐).
- 변형 방향: 채점 기준을 작품 주인공의 출신(용병, 의원, 상인 등)에 맞는 잣대로 바꾼다.

**V6. 화법 서열과 시대 불일치** [공통 / 속어는 서명]
- 조작: 어른·권위자는 고풍 해라체·하오체·하게체, 주인공은 반말이나 '무례한 해요체'(공손한 어미에 무례한 내용). 주인공은 진심으로 존중하는 한두 명 앞에서만 하십시오체를 쓴다. 거만한 적에게는 무협에 어울리지 않는 현대 속어로 응수한다.
- 기능: 어미만으로 관계와 존중의 크기가 전달되고, 시대 불일치가 웃음을 만든다.
- 정당: 속어는 응징·개그 장면, 격식체는 윗사람과의 감정 장면.
- 결함: 모든 인물이 같은 어미, 주인공의 격식체 남용(존중 신호가 무뎌짐), 진지 장면의 현대 속어.
- 변형 방향: 속어는 참고작 고유 재료 대신 작품 고유 재료(작품 시대감에 맞는 다른 계열의 현대어)로 바꾼다.

**V7. 현재형 근접 촬영** [공통]
- 조작: 표정이 변하는 찰나, 동작이 시작되는 찰나에 현재형 '~ㄴ다'를 섞는다. 개그 화당 3~6회, 진지 1~3회, 분노 0~2회, 존중형 결투 8~10회.
- 기능: 독자를 현장에 세워 두는 실황 효과.
- 정당: 근접 시각 묘사, 존중형 결투의 정점.
- 결함: 장면 전체를 현재형으로 써서 단조로울 때, 분노 장면에서 남발할 때(시간이 가벼워짐).

**V8. 부재자의 목소리** [공통 표기 / 말대꾸는 서명]
- 조작: 죽었거나 떠난 인물의 말은 줄머리 '- '로 표기해 현재 독백에 끼워 넣는다. 철학, 정보, 말대꾸 모두 이 통로로 전달한다.
- 기능: 과거가 현재 판단에 직접 개입해 회상이 설명이 아니라 사건이 된다.
- 정당: 수련 돌파의 열쇠, 허세의 정보 근거, 회상.
- 결함: 한 장면 3회 이상, 회상 대사가 4문단 이상 길어질 때.
- 변형 방향: 고인의 목소리 대신 유품에 남은 글귀, 습관처럼 떠오르는 가르침 등 통로를 바꿀 수 있다.

## 리듬

**R1. 한 줄 문단 기본** [공통]
- 조작: 문단은 1~2문장. 반전, 판정, 단어 하나짜리 정리는 단독 문단. 2~4문장 문단은 해설, 적의 공포, 깨달음의 이완, 존중형 결투의 감속 구간에만 허용한다. 개그 장면은 한 줄 문단 80% 이상, 슬랩스틱은 85% 이상(대략).
- 기능: 모바일 화면에서 시선이 끊기지 않고, 단독 문단이 '박자'가 된다.
- 결함: 해설 구간까지 한 줄씩 쪼개 정보가 흩어질 때.

**R2. 길이 비대칭** [공통]
- 조작: 긴 위협·폭주·논리(30~150자) 하나에 짧은 반응(1~5자) 2~3개를 붙인다. 허세 장면에서는 위협 대 대답이 20:1 이상.
- 기능: 짧은 쪽이 긴 쪽을 이기는 것처럼 느껴진다.
- 결함: 짧은 반응만 연속되어 정보가 없을 때.

**R3. 정적 장치** [공통]
- 조작: 말없음표 단독 대사, 접속사+말줄임 단독 문단, 한 문장의 3문단 분할(앞 절반, 억누르는 서술, 뒤 절반), 큰 소리 뒤의 작은 소리. 장면당 2~4회.
- 기능: 줄바꿈이 멈칫과 정적을 만든다.
- 결함: 말없음표 대사 2개 연속에 의미 차이가 없을 때, 장면당 5회 이상.

**R4. 의성어 크기 곡선** [서명]
- 조작: 장면 유형마다 의성어 배치 모양을 다르게 한다.
  - 일상 개그: 큰 소리로 절단, 작은 소리로 버튼
  - 교정형 결투: 정점에서 모음 6~7개 장음 1회
  - 존중형 결투: 상대의 공세는 같은 소리 3회 균일 반복, 결정타는 소리 0
  - 응징형: 작품 최장(모음 10개 이상) 1회
  - 고전 전투: 한 줄에 3~4개 불규칙 연타, 마지막을 약하게
  - 분노: 발소리 반복 횟수 1, 2, 3회
- 기능: 소리의 모양만으로 장면의 성격이 전달된다.
- 결함: 모든 장면에 같은 강도의 의성어, 분노 장면의 우스운 의성어.
- 변형 방향: 의성어 어휘 자체(어떤 소리를 쓰는지)는 작품 고유로 새로 만든다.

**R5. 최장 의성어의 희소성** [서명]
- 조작: 슬랩스틱의 타격음은 작품 최장으로 쓰고, 다른 장면의 의성어는 그보다 짧게 유지한다.
- 기능: 최장 기록이 펀치라인이 되려면 희소해야 한다.
- 결함: 최장 길이를 여러 장면에 반복할 때.

**R6. 소리 0의 결정타** [서명]
- 조작: 존중형 결투에서 가장 큰 소리 바로 뒤에 소리를 0으로 두고, 결정타는 상대 감각 속 작은 이상 하나를 40~70자의 느린 문장으로 묘사해 대체한다.
- 기능: 강함을 '보이지 않음'으로 증명해 주인공의 격이 상대의 폭풍보다 위에 놓인다.
- 결함: 결정타에 기술명과 의성어를 다시 붙일 때(상대와 같은 체급이 됨).
- 변형 방향: 결정타를 대체하는 감각은 참고작 고유 재료 대신 작품 고유 재료(무게 변화, 온도, 사라진 소리 같은 다른 감각)로 바꾼다.

**R7. 경구와 반복** [공통]
- 조작: 교훈은 경구 한 문장 단독 문단으로, 체념은 같은 단어 반복에 수식어를 덧붙여 리듬을 만든다.

**R8. 결정 대사로 화 끊기** [공통]
- 조작: 화 경계는 결정적 대사 직후에 두고, 그 대사를 다음 화 제목으로 써서 (1)(2)로 분할한다.
- 기능: 독자가 하루 동안 그 대사를 곱씹는다.

**R9. 리플레이** [서명]
- 조작: 개그 정점에서 화를 끊었다면, 다음 화는 현재형 1어절 후렴 동사로 같은 장면을 다른 각도에서 다시 보여 준다. 새 디테일을 하나 이상 더한다.
- 기능: 한 방의 쾌감을 두 번 음미한다.
- 정당: 응징형 슬랩스틱 직후 1회.
- 결함: 후렴 3회 이상, 새 디테일 없는 반복.
- 변형 방향: 후렴 동사와 리플레이 각도(누구의 눈으로 다시 보는지)를 매번 바꾼다.

## 개그 문법

**G1. 주변이 망가진다** [서명]
- 조작: 주인공이 직접 웃기지 않는다. 주인공은 원인이거나 마지막에 태연하게 버튼(행동이나 소리 한 줄)을 누른다. 일상 개그의 시점 인물은 '상식적인 피해자'로 잡고, 주인공 대사는 0~2줄.
- 기능: 웃음의 범위가 주인공 한 명에서 세계 전체로 넓어진다.
- 결함: 주인공이 농담을 연발하는 원맨쇼.
- 변형 방향: 버튼 행동은 참고작 고유 재료 대신 작품 고유 재료(작품 주인공의 습관 행동)로 바꾼다.

**G2. 결핍이 연료** [서명]
- 조작: 무협의 가치(규율, 체면, 명예, 서열)가 생계 앞에서 굴복하는 장면을 화당 1회 이상. 같은 결핍 모티프 단어를 개그 파도마다 반복한다.
- 기능: 인물이 망가지는 이유가 공감 가능해져 웃음에 정이 붙는다.
- 결함: 결핍 없이 성격 이상만으로 망가질 때.
- 변형 방향: 돈·밥 대신 작품 세계의 다른 결핍(약재, 땅, 명성, 수면, 빚진 은혜 등)을 연료로 쓴다.

**G3. 눈사태형** [서명]
- 조작: 짧은 쌓기 6~8줄, 폭주 2~3파도(파도마다 길이 20~40% 증가, 사이에 피해자의 따옴표 없는 속말 한 줄), 단어 중간에서 큰 의성어와 제3자 개입으로 절단, 정적, 작은 버튼.
- 기능: 웃음이 한 방이 아니라 커지는 파도로 와서 오래 지속된다.
- 결함: 절단 없이 폭주가 끝까지 가서 지칠 때, 파도가 4회 이상.

**G4. 김빼기** [공통 형태 / 사적 원한은 서명]
- 조작: 성장이나 감사가 완성된 직후 1~3어절 대사 핑퐁 4~6회로 주인공의 세속적 요구나 사적 감정을 터뜨린다. 장면당 1회.
- 기능: 교훈극의 무게를 덜고 주인공을 성자가 아닌 인간으로 만든다.
- 결함: 깨달음 한가운데, 분노 장면, 존중형 결투, 같은 장면 2회.
- 변형 방향: 원한 대신 값 청구, 부탁, 엉뚱한 관심사 등으로 바꾼다.

**G5. 겉과 속의 분리** [서명]
- 조작: 긴장된 대치에서는 개그를 내면(하소연, 회상)에서만 터뜨리고 겉 표정은 '어두워짐' 정도로 유지한다.
- 기능: 독자는 웃지만 상대는 긴장한 상태라 장면의 긴장이 깨지지 않는다.
- 결함: 내면 개그가 겉 대사로 새어 나와 상대까지 웃길 때.

**G6. 보조 장치** [혼합]
- 평판 후제시 [서명]: 망가진 인물의 평소 평판은 붕괴 '후'에 1~2문장으로. 기능: 반전을 본 뒤 맥락을 들어 두 번 웃는다.
- 말실수 자기정정 [공통]: 속내를 말하다 체면어로 고쳐 말한다.
- 주변인 착각 [공통]: 피해자가 상대를 자기편이라 믿는다.
- 피해자 합창 [서명]: 피해자 여럿의 속 욕설을 작은따옴표로 2~4줄 연달아. 각 줄의 내용이 달라야 한다.
- 지연 이중 확인 [공통]: 정보를 흘려듣고 단어를 반복하다 멈추는 지연 반응.

## 온도 전환

**T1. 개그에서 서늘함으로** [서명]
- 조작: 같은 화 안에서도 가능하다. 전환점은 '도착'이나 '소리' 한 줄. 그 순간부터 주인공의 속말과 농담 0회.
- 기능: 낙차가 클수록 서늘함이 깊어진다.
- 결함: 전환 후 한 줄이라도 개그가 남을 때.

**T2. 서늘함에서 개그로** [공통 / 복귀 지점은 추정]
- 조작: 화 경계를 넘긴 뒤에만. 첫 웃음은 주인공이 아닌 주변인 반응에서.
- 결함: 같은 화 안에서의 복귀(피해의 무게가 증발함).

**T3. 응징형과 분노형의 경계** [서명]
- 조작: 동료가 '모욕'당했으면 응징형 개그, 동료가 '피를 흘렸으면' 분노형. 피가 섞이면 개그 0.
- 기능: 주인공이 언제 웃고 언제 웃지 않는지가 독자에게 일관된 신호가 된다.

**T4. 회상의 슬픔과 개그** [서명]
- 조작: 개그 탈선 직후 1~3문단 안에 상실의 사실 한 줄(감정어 없이). 장면의 마지막 음은 상실이나 여운. 주인공을 보살피는 윗사람과의 감정 장면은 개그 0.
- 기능: 웃은 직후라 상실이 더 아프게 들어온다.
- 결함: 개그로 끝나는 회상, 상실 직후 다시 개그.

**T5. 진지한 철학과 거친 입** [서명]
- 조작: 무학의 정수는 거친 입(주인공의 꾸짖음, 죽은 선배의 호통)에서 나오게 하고, 서술이 단정문으로 승인한다.
- 기능: 교훈이 설교가 되지 않고, 거친 인물에게 깊이가 생긴다.
- 결함: 거친 말투가 내용까지 틀리게 만들 때.

**T6. 고전 전투의 경쾌함** [서명]
- 조작: 농담 대신 팀 호령의 기세와 무모함으로 경쾌함을 유지하고, 적의 위협 제스처 한 번으로 뒤집은 뒤 화 경계 너머 동료의 공포로 넘긴다.

## 금지

1. 원작 문장의 인용, 대사 한 줄, 단어만 바꾼 재작성.
2. 원작 장면의 상황, 박자 순서, 대사 구조를 이름만 바꿔 따라가는 것.
3. 주인공의 분노 독백이나 각성 선언형 대사. 분노는 침묵과 행동으로만.
4. 감정을 이름으로 부르는 문장, 개그를 서술자가 해설하는 문장.
5. 강함을 형용사로만 주장하는 것. 산술 비교, 질적 비교, 주인공의 이례적 태도, 작품 내 이전 상대와의 교차 참조 중 하나로 반드시 측정한다.
6. 존중형 결투에서 무결한 주인공. 휘청임이나 통증 1회 이상.
7. 경맥 이름을 나열하는 내공 묘사 3문단 이상, 상태창식 성장 목록.
8. 깨달음 한가운데, 분노 장면, 존중형 결투, 윗사람이 주인공을 품는 감정 장면의 개그.
9. 같은 장면 김빼기 2회 이상.
10. 실제 중상이나 죽음에 슬랩스틱·모의 서사시 어휘를 쓰는 것.
11. 고유명사·고유 설정·대표 대사 문구는 작품 `book_rules`의 금지로 검사한다.

## 장면 유형 고르기

- 일상: 문파 안의 사소한 갈등을 주변 인물의 붕괴로 키워 웃길 때. → scene-patterns.md 일상
- 분노: 동료가 피를 흘린 직후, 주인공 목소리를 지우고 적의 공포로 무게를 쌓을 때. → 분노
- 허세: 강한 상대와 대치하며 겉은 태연하게, 속은 하소연으로 협상할 때. → 허세
- 수련: 경지 돌파(단독) 또는 훈련 풍자(집단)로 성장을 보여 줄 때. → 수련
- 회상: 부재자의 목소리로 지금의 선택을 설명하고 상실로 끝낼 때. → 회상
- 화 끝 훅: 제3자의 정보 폭로나 저속과 장엄의 낙차로 다음 화를 당길 때. → 화 끝 훅

## 전투 패턴 고르기

planner는 아래 요약으로 카드를 고르고, 세부는 combat-patterns.md 고르기 표를 본다.

**압도 전투의 태도 분기** [서명]: 압도 전투는 상대의 강함이 아니라 태도로 카드를 고른다. 같은 권(10~20화) 안에서 세 형을 모두 한 번씩 쓰면 주인공의 기준이 독자에게 각인된다.
- 실력 없이 거만하고 모욕한 상대 → C1 일격 압살
- 실력보다 높은 것을 탐한 상대 → C2 농락전(교정형)
- 밑바닥까지 다 쏟은 상대 → C6 고수 대결(존중형)

| 카드 | 한 줄 요약 |
|---|---|
| C1 일격 압살 | 거만한 상대를 한 방에, 느린 인식과 만화 물리학, 리플레이 |
| C2 농락전 | 상대 기술을 생활 동작으로 깨고 꾸짖으며 가르침, 끝에 김빼기 (장시간 농락은 미관찰) |
| C3 고전·역전 | 팀 호명, 신뢰 합격, 적의 위협 제스처로 뒤집힘 (역전 부분은 미관찰) |
| C4 다대일 | 다수의 돌격을 한 번에 쓸어 냄, 적의 산술적 공포 (부분 관찰) |
| C5 관전자 시점 | 관전자의 확신을 쌓고 무너뜨림, 리플레이 각도 |
| C6 고수 대결 | 상대의 전력을 받아 주고, 결정타는 보이지 않게, 인정 한 줄 |
| C7 분노 전투 | 주인공 목소리 0, 피해 나열, 발소리 메트로놈, 평소와 다른 검 |
| C8 집단전 | 서열 역전 호령, 동료 개성 형용사, 위아래 협공 |
| C9 전투 직후 | 강평, 패자 성찰, 정적, 동료 공포 중 전투 형에 맞는 것 |

## 검수 판정 기준

auditor는 엔진 기본 규칙으로 결함을 표시하기 전에, 해당 표현이 아래 '의도된 장치'인지 먼저 확인한다. 의도된 장치이고 '정당한 경우'의 조건을 모두 충족하면 결함으로 표시하지 않는다.

### 의도된 장치

| 장치 | 정당한 경우 | 결함인 경우 |
|---|---|---|
| 군중 일제 반응 (장내 침묵, 일제히 물러섬, 일제 함성) | 주인공 행동의 크기를 재는 계측기로 장면당 1~2회 쓰고, 직후 1~3문장 안에 개별 인물 1명의 시점이나 반응으로 좁힐 때 | 이유 없는 일제 감탄, 장면당 3회 이상, 개별화 없이 끝날 때, 분노 장면에서 군중이 감탄할 때 |
| 피해자 합창 (여럿의 속말 연속) | 집단 수련·집단 피해 개그에서 2~4줄, 각 줄 내용이 서로 다를 때 | 같은 내용의 반복, 진지·분노 장면, 5줄 이상 |
| 같은 어미 연속 (현재형 '~ㄴ다' 묶음) | 실황 구간(존중형 결투 정점, 근접 시각)에서 3~4문장 묶음 | 장면 전체가 같은 어미, 분노 장면의 현재형 남발 |
| 같은 어미 연속 (과거형 '~었다' 묶음) | 분노·고전 전투의 묵직한 서술, 피해 나열 직후 | 개그 장면에서 같은 과거형 어미가 5문장 이상 이어져 리듬이 죽을 때 |
| 후렴 동사 반복 | 리플레이 신호로 화 경계 앞뒤 2회 | 3회 이상, 리플레이가 아닌 곳 |
| 발소리 의성어 반복 | 분노 장면에서 1, 2, 3회로 횟수가 늘 때 | 횟수가 고정되거나 줄 때, 개그 장면 |
| 같은 의성어 균일 3회 | 존중형 결투에서 상대의 집념을 표현할 때 | 다른 장면의 단조로운 반복 |
| '~을 말이다' 도치 종결 | 장면당 1~3회, 지연과 여운 | 연속 2문장, 개그 장면 남발 |
| 과장 (멜로 과장, 만화 물리학, 모의 서사시) | 원인이 사소하거나 중상이 아닌 맥락이고, 직후 한 줄로 끊을 때 | 실제 비극·중상, 분노 장면, 같은 장면 연속 2회 |
| 비속어 | 개그·일상·응징 장면에서 1~3회, 주인공 화법 | 분노·존중형 결투·윗사람 감정 장면 |
| 말없음표 단독 대사 | 충격 직후 1박, 장면당 1~4회 | 의미 차이 없는 2개 연속, 장면당 5회 이상 |
| 단어 하나짜리 단독 문단 | 판정, 반전, 명명 | 해설 구간까지 쪼갤 때 |
| 김빼기 | 성장·감사 완성 직후 1회 | 깨달음 중, 분노, 존중형 결투, 2회 |
| 서술자 비꼼 | 개그·일상·허세 | 분노, 윗사람과의 회상 |
| 최장 장음 의성어 | 응징형 정점 1회 | 여러 장면 반복 |
| 주인공 목소리 0 | 분노 장면 | 다른 장면(주인공 실종) |
| 주인공 격식체 | 진심으로 존중하는 윗사람 앞 | 상대를 가리지 않는 남용 |

### 등급 규칙

엔진의 감사 값에 이렇게 대응시킨다. 의도된 장치는 정당 조건을 충족하면 기록하지 않는다. 장치 자체를 이유로 issue를 만들지 않는다.

| 등급 | 기준 | 엔진 값 | 처리 |
|---|---|---|---|
| 통과 | 의도된 장치가 정당 조건 충족, 수치가 범위 안 | 기록하지 않음 | 그대로 둔다 |
| 경미 | 수치가 범위에서 30% 이내로 벗어남, 장치 1회 과용, 정적 장치 하나 누락 | `observation` | observation으로 보고한다(수정은 사용자가 revise를 부를 때 국소 수정) |
| 중대 | 장치의 위치 오류(분노 장면 개그, 깨달음 중 김빼기), 주인공 목소리 규칙 위반, 장면 유형·전투 카드 오판, 무게 붕괴(비극에 슬랩스틱) | `issue` | issue로 보고한다(수정은 사용자가 revise를 부를 때 해당 박자를 다시 쓴다) |
| 치명 | 원작 문장 재현, 원작 장면 구조를 이름만 바꿔 따라감, 작품 `book_rules`의 금지 위반 | `issue` | issue로 보고한다(수정은 사용자가 revise를 부를 때 장면 전체를 다시 쓴다) |

- 한 장면에 경미 3개 이상이면 중대(`issue`)로 올린다.
- 한 화에 중대 2개 이상이면 issue로 보고하고 화 전체를 다시 써야 한다고 적는다(수정은 사용자가 revise를 부를 때).

### 수정 규칙

reviser는 사용자가 revise를 부를 때 다음을 따른다.


1. 의도된 장치는 지우지 말고 정당 조건에 맞춘다. 군중 일제 반응이 결함이면 삭제하지 말고, 직후에 개별 인물 1명의 반응을 붙여 좁힌다.
2. 과용은 가장 약한 것부터 지운다. 의성어가 넘치면 정점의 것을 남기고 주변 것을 지운다. 말없음표가 넘치면 충격 직후가 아닌 것부터 지운다.
3. 위치 오류는 옮기거나 지운다. 분노 장면의 개그는 지운다. 옮길 곳이 있으면(다음 화 첫 주변인 반응) 그쪽으로 옮긴다.
4. 무게 붕괴는 어휘를 바꾼다. 중상에 쓴 슬랩스틱 어휘는 묵직한 과거형 서술로 바꾸고, 사소한 일에 쓴 비극 어휘는 멜로 과장 + 한 줄 끊기로 바꾼다.
5. 같은 어미 반복이 결함이면 어미를 바꾸기 전에 문단을 먼저 나눈다. 한 줄 문단으로 끊으면 어미 반복이 박자가 되는 경우가 많다.
6. 주인공 목소리 위반은 장면 유형의 V4 기준으로 되돌린다. 분노 장면의 독백은 적 시점의 관찰 문장으로 바꾼다.
7. 치명 등급은 부분 수정하지 않는다. 새 상황, 새 소품, 새 순서로 장면을 다시 설계한다.
8. spot-fix·polish에서는 문체 장치를 다른 장치로 바꾸지 않고, 지적된 문장만 고친다.
