# 한국어 문장 정리

사용자가 원고가 뻔하다, 기계적이다, 설명이 많다, 반복된다, AI가 쓴 것 같다고 말할 때 쓴다.

- 금지어를 세거나 일괄 치환하지 않는다. 문장의 기능과 효과를 읽고 진단한다.
- 실제 결함과 정당한 목소리 선택을 구별한다. 반복은 리듬일 수 있고, 추상은 의도일 수 있고, 짧은 문장은 압박일 수 있다.
- 장르 문체 스킬이 정한 장치는 목소리 선택으로 본다.
- 찾을 것: 근거 없는 결론, 장면 증거 없는 감정 이름표, 어디에나 들어갈 전환 문장, 대칭으로 짜인 상투 표현, 같은 해석의 반복, 장식적 디테일, 장면을 대신한 요약, 정보만 옮기는 대사.
- 한국어에서 특히 볼 것: 번역투(`~하는 것이었다`, `되어지다`, `그녀`·`그것` 남용, `~를 가지다`), 같은 어미(`~했다`)와 같은 문장 시작(`그는`, `그리고`)의 연쇄, 주어를 매번 다시 쓰는 문장, 이유 없이 흔들리는 호칭·존댓말, 모든 인물이 같은 말투.
- 진행 중인 작품에서 범위가 불분명하면 먼저 검수한다. 허가된 다시 쓰기는 reviser로 한다. 대체 원고를 채팅에 붙여 넣고 저장됐다고 말하지 않는다.
- 사건 사실, 시점, 인물의 목소리, 증거, 속도의 기능, 원문의 좋은 문장을 보존한다.
- 사용자의 언어로 답한다.

문단 단위 진단이나 수정 지시서를 만들 때 `references/semantic-cleanup.md`를 불러온다. 번역투·호칭·대사의 구체적인 기준은 장편 집필 스킬(inkos-long-writing)의 한국어 문장 기준과 같다.
