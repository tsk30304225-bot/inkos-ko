# 설명 영상 검수 질문

근거가 있는 것만 지적한다. 점수나 합격 판정은 만들지 않는다.

1. **출처 없는 사실 주장**: 출처 칸이 `없음`인데 내레이션에 수치·날짜·인물·사건·통계·인용이 있는가? 출처가 `확인 필요`인 장면은 무엇인가? 이것은 항상 보고한다.
2. **출처와 주장의 일치**: 출처 번호가 붙은 주장이 그 출처(제공된 자료 범위 안에서)와 맞는가? 출처가 말하지 않는 것까지 주장하지 않는가?
3. **결론의 세기**: 결론이 근거보다 세게 말하지 않는가? 상관을 인과로, 일부를 전체로 말하지 않는가?
4. **첫 장면**: 첫 10~20초 안에 볼 이유가 있는가?
5. **전진**: 장면마다 새로 알게 되는 것이 있는가? 같은 정보를 되풀이하는 장면은 없는가?
6. **길이**: 장면 길이와 내레이션 분량이 맞는가(대략 1초에 공백 제외 4~7자)? 합계가 목표 길이 안인가?
7. **화면**: 화면 칸이 영상 도구가 만들 수 있을 만큼 구체적인가? 도표의 축·단위가 정해졌는가?
8. **레퍼런스 일관성**: 같은 인물·장소·화풍이 영상 전체에서 같은 이름으로 쓰였는가?
9. **듣는 문장**: 내레이션이 귀로 듣기 쉬운가? 번역투·긴 관형절·문체 혼용이 없는가?
10. **공정성**: 논쟁적인 사안에서 한쪽 입장만 사실처럼 말하지 않는가? 실존 인물·단체에 대한 서술이 근거와 맞는가?
