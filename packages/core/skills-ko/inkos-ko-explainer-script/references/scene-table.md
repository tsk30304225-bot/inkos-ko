# 장면 표 형식

산출물은 아래 Markdown 구조를 정확히 따른다. 제목 문자열과 표의 열 이름·순서를 바꾸지 않는다(형식 검사가 이 이름으로 읽는다).

```
# 영상 제목

## 개요
- 중심 질문: …
- 대상 시청자: …
- 목표 길이: …초
- 문체: 해요체

## 장면 목록

| 장면 | 길이(초) | 내레이션 | 화면 | 레퍼런스 | 출처 |
| --- | --- | --- | --- | --- | --- |
| 1 | 15 | 내레이션 원고 | 보여줄 화면 | 화풍: …; 배경: … | 없음 |
| 2 | 32 | … | … | … | [1] |

## 출처
- [1] 자료 제목 — 저자·기관, 발행일, URL
```

규칙:

- `장면`은 1부터 빠짐없이 이어지는 정수.
- `길이(초)`는 양의 정수(초). 합계가 목표 길이 범위 안에 들어가야 한다.
- 모든 칸을 채운다. 칸 안에서 줄을 바꾸지 말고, 필요하면 `<br>`을 쓴다. 칸 안에 `|` 문자를 쓰지 않는다.
- `출처`는 `[번호]`(여러 개면 `[1][2]`), `없음`(사실 주장이 없는 장면), `확인 필요`(근거를 찾지 못한 사실 주장) 중 하나.
- `[번호]`는 `## 출처` 목록에 있어야 한다. 목록의 모든 번호는 한 번 이상 쓰여야 한다.
- 레퍼런스는 `화풍:`, `인물:`, `배경:`, `목소리:` 항목을 `;`로 구분한다. 해당 없으면 `없음`.

형식 검사(코드)가 확인하는 것: 필수 제목, 열 이름과 순서, 장면 번호 연속성, 길이 정수와 합계, 빈 칸, 출처 번호의 존재. 검사 결과는 `explainer-check.md`에 기록되며 원고를 자동으로 거절하지 않는다.
