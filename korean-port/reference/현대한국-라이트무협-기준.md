# 현대 한국 라이트 무협 설정·검수 기준

## 현대 한국 라이트 무협 편집 기준
이것은 해당 작품에 적용할 기본 편집안이며 시장 전체의 공식 표준이나 특정 작품 모방 지시가 아니다. 작가가 정한 정통/신무협·코미디·진중함·로맨스 비중이 우선한다.
무협의 중심 약속은 무공의 사용과 대가, 강호의 관계·명분·책임, 주인공의 선택이 만드는 변화다. 가독성 높은 한국어와 빠른 접근성을 지향하되 '라이트'를 유아적 말투·상시 개그·무조건 무적·갈등 삭제로 해석하지 않는다. 강호 배경을 현대 한국이나 실제 중국사의 특정 왕조로 자동 확정하지 않는다.
각 설정 항목은 목적·맥락·기준·경계를 밝혀 아래 선택을 구체화한다.
1. 독자 약속/정서: 통쾌함·성장·문파 생활·동료 관계·추리·연애 중 중심과 보조를 고르고 사건으로 확인할 성취를 둔다. 고난은 선택과 변화에 기여해야 하며 근거 없는 매 회차 고구마/사이다 비율을 시장 법칙처럼 강제하지 않는다.
2. 주인공: 지금 원하는 일과 당장 행동할 이유, 결핍, 장점, 하지 않을 행동, 실수의 수습 책임을 정한다. 회귀·빙의·환생·천재성·기연·시스템은 선택 장치이며 무협 필수 요소가 아니다. 과거 지식/능력에는 아는 범위와 실패 조건을 둔다.
3. 문파/가문/정사마/관: 재원·지리·무력·명분·내부 이해관계·인재 재생산·이탈 대가를 정한다. 정파=항상 선, 사파/마교=항상 악으로 단정하지 않으며 어느 집단도 이유 없는 전지전능으로 만들지 않는다. 관과 무림의 충돌/불간섭은 이유와 예외가 있어야 한다.
4. 무공/내공/경지: 작품 내부의 명칭과 상대 강함을 먼저 정의하고 거리·숙련·호흡·지형·상성·부상·병기·동료 개입을 승패 근거로 둔다. 내공의 양, 운용 숙련, 육체, 경지는 동일한 값이 아니다. 경지 이름이나 순서는 작품마다 선택하며 화경/현경/생사경을 보편 필수 사다리로 고정하지 않는다. 상위 경지를 이기면 사전 단서·조건·소모·후유증을 남긴다.
5. 수련/기연/영약: 획득 경위·학습 과정·사용 제약·회복 시간·누적 대가·소유 분쟁을 정한다. 영약으로 모든 부상과 내공을 즉시 복구하거나 새 비급이 이전 규칙을 소급 무효화하지 않는다. 경제는 수치 시스템을 선택했을 때만 장부로 강제한다.
6. 관계/호칭/대사: 사문 항렬·직책·사제/사형제·은원/빚·친밀도에 맞춰 호칭을 정하고 달라지는 계기를 기록한다. 장문인/가주/방주 등은 조직 구조에 맞춘다. 현대식 유머·독백은 작품 톤의 허용 범위를 정하며 모두가 같은 인터넷 말투를 쓰지 않게 한다.
7. 대결: 장면 목표→거리와 위험→행동/대응→판단의 반전→결과/대가를 독자가 따라가게 쓴다. 초식 이름 나열과 기세 설명만으로 결과를 대신하지 않는다. 모든 싸움을 장편 결전처럼 쓰지 않고 중요도에 맞춰 압축한다.
8. 연재/전개: 도입에서 욕망·장애·장르 약속을 장면으로 보여주고 설명은 쓰이는 순간 나눈다. 매 회차 사건·정보·관계·결정 중 의미 있는 변화가 있어야 한다. 수련/일상/호흡 회차도 기능이 있으면 허용한다. 소보상·권말 성취·전체 결말은 서로 연결하고 절단신공과 반복 오해로 시간을 채우지 않는다.
9. 혼합 장르/수위/결말: 선협의 승천·법칙/초월 세계, 서양식 마법/게임 수치, 헌터/현대 배경 등은 작가가 선택한 혼합 범위 안에서만 사용한다. 폭력·연애·성적 표현의 허용 수준과 금지를 별도로 정한다. 결말은 주된 은원·목표·관계·대가를 회수하며 시리즈 확장을 위해 해결한 갈등을 근거 없이 되돌리지 않는다.
모든 항목은 현대판타지·로맨스·미스터리와 동일하게 인과·능동적 선택·정보 공정성·대가·연속성으로 검수한다. 특정 장르의 문법을 다른 장르에 자동 이식하지 않는다.

## 항목 작성 예시 — 내공 회복

아래는 형식 예시이며 새 작품의 확정 설정이 아니다.

- **목적:** 전투 이후의 휴식과 재대결 선택에 실제 비용을 만든다.
- **맥락:** 초급 심법을 익힌 주인공은 내상을 입은 상태이며, 추격자가 반나절 뒤 접근한다.
- **기준:** 정상 수련 때와 부상 시의 회복 조건을 구별하고 다음 대결의 호흡·운용 가능 범위에 반영한다. 수치를 택했다면 원장과 일치시킨다.
- **경계:** 영약·기연은 사전에 정한 효과만 내며, 회복으로 소실한 무공 숙련이나 부러진 병기가 자동 복원되지는 않는다. 회복량·시간은 작가가 정하기 전까지 미정이다.

## 설정 선택의 상태

`확정`은 작가가 선택했거나 실제 정사로 확인한 내용, `제안`은 검토할 편집안, `미정`은 아직 선택하지 않은 내용이다. 회귀 여부, 배경 시대, 주인공의 성별, 무력 경지, 시점, 로맨스 비중, 수위, 목표 플랫폼은 이 지침만으로 확정하지 않는다.

한국 무협은 한국어 독자를 위한 장르 문법을 뜻하며 한국 지리·역사 배경을 필수로 요구하지 않는다. 특정 인기작의 인물·문파·고유 설정을 그대로 옮기는 기준도 아니다.
