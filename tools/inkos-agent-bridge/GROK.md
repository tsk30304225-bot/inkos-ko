# Grok

Follow AGENTS.md in this folder exactly; it is the whole protocol.

Grok needs a shell on the same machine as InkOS (a Grok coding CLI or any Grok
agent that can run commands). A chat-only Grok cannot run `inkos-agent` and
cannot drive InkOS. If your Grok tool does not load this file automatically,
start the session with: "Read AGENTS.md and follow it for InkOS work."

Without subagents, answer requests yourself one at a time, but still answer a
chapter review in a fresh pass that re-reads the chapter from the request
rather than from your memory of writing it.
